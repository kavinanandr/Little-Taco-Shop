# 🌮 Little Taco Shop

A responsive, multi-page website for a fictional taco shop, built using **HTML5 and CSS3**. This project focuses on semantic HTML, clean page structure, consistent styling, and responsive web design.

## 📌 About the Project

Little Taco Shop is a beginner-friendly front-end web development project that presents information about a fictional taco restaurant. It includes separate pages for the home page, menu, operating hours, and contact information.

The project demonstrates the fundamentals of building structured, accessible, and visually consistent websites using HTML and CSS.

## ✨ Features

- **Home Page:** Introduces the taco shop.
- **Menu Page:** Presents the shop's menu.
- **Hours Page:** Displays operating hours.
- **Contact Page:** Provides contact information.
- **Responsive Design:** Uses CSS to adapt the layout to different screen sizes.
- **Semantic HTML:** Uses meaningful HTML elements to organize page content.
- **Reusable Styling:** Maintains consistent design through a shared CSS stylesheet.
- **Multi-page Navigation:** Separates content into dedicated HTML pages.

## 🛠️ Technologies Used

- **HTML5** — Page structure and semantic markup.
- **CSS3** — Styling, layout, and responsive design.
- **Git and GitHub** — Version control and project hosting.

## 🚀 Getting Started

You can run this project locally without installing any dependencies or build tools.

### Prerequisites

- A modern web browser.
- Git (optional, for cloning the repository).

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/kavinanandr/Little-Taco-Shop.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Little-Taco-Shop
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in Visual Studio Code for a convenient local development experience.
